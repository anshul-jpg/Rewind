# **App Name**: Rewind

## Core Features:

- File Upload: Upload a JSON file containing watch history data.
- Data Parsing: Parse the uploaded JSON file to extract video title URLs.
- Video ID Extraction: Extract video IDs from the title URLs.
- YouTube API Integration: Fetch video durations from the YouTube Data API using video IDs.
- Duration Conversion: Convert ISO 8601 duration format to total minutes.
- Total Watch Time Calculation: Calculate the total watch time in minutes from the video durations.
- Channel Analysis: Determine the top 5 most-watched channels.
- Monthly Watch Time Chart: Generate data for a bar chart showing watch time per month.
- Dashboard Display: Display the calculated data and the Recharts bar chart in a user-friendly dashboard.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) for a sense of professionalism and focus.
- Background color: Light gray (#F0F4F8) to ensure comfortable readability and a clean interface.
- Accent color: Soft teal (#64FFDA) to highlight interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, machined, objective, neutral look.
- Utilize a grid-based layout with clear sections for data display and charts.
- Employ simple, outline-style icons to represent data categories and actions.
- Incorporate subtle animations when loading data or updating charts to enhance user experience.
